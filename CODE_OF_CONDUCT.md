# Codice di condotta

Questo progetto adotta il [Contributor Covenant v2.1](https://www.contributor-covenant.org/it/version/2/1/code_of_conduct/).

In breve: siate rispettosi, costruttivi e accoglienti; niente molestie, attacchi
personali o comportamenti tossici — nemmeno se il vostro portiere ha preso 4 gol
alla prima giornata. Le segnalazioni si fanno tramite la segnalazione privata del
repository (tab *Security*) o contattando il maintainer via GitHub.
